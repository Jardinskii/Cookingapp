# DailyCook

A polished prototype for a cooking web app that helps people decide what to cook each week, estimate grocery costs, and jump to grocery delivery checkout.

## Open the Prototype

Open `index.html` in a browser. It runs without sign-in, install steps, or live grocery APIs.

## What Is Included

- One-question-at-a-time onboarding for ZIP code, household size, weekly meal count, budget, dietary restrictions, avoided foods, cooking time, skill level, calories, and recommendation style.
- A visual meal gallery with 60+ sample meals and local meal thumbnail images.
- Meal selection with an estimated weekly plan cost.
- A generated grocery list with sample prices for Instacart, Walmart, Kroger, Safeway, Costco, and Target.
- Store filter chips, per-item price selection, cheapest-cart helper, and weekly budget comparison.
- A final cart screen with checkout links.

## Notes

The grocery prices are sample prototype data. The project also includes a React/Sites source version under `app/`, but the standalone `index.html` version is the easiest way to preview the app in this environment.
